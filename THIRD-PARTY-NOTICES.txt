Project: https://github.com/yt-dlp/yt-dlp

Role: Media retrieval (invoked as a standalone executable)

yt-dlp is a feature-rich command-line audio/video downloader. Slate downloads
the standalone yt-dlp.exe into its own engine folder on first use (or when the
user triggers an install), so the exact version depends on the latest release
available at install time. Verify the installed version with `yt-dlp --version`.
